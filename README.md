# Dr. Showkat Ahmad Dar — Academic Portfolio

A responsive, single-page academic portfolio built with plain HTML, CSS, and JavaScript for GitHub Pages.

## Files
- `index.html` — profile, research interests, selected publications, academic journey, and contact links
- `style.css` — responsive visual design
- `script.js` — mobile navigation and current year
- `cv.pdf` — downloadable CV copied from the supplied document

## Publish on GitHub Pages
1. Download and extract this ZIP.
2. Open your GitHub account: https://github.com/showkatme2009
3. Create a **new public repository** named `showkatme2009.github.io` (if that repository does not already exist).
4. Upload all four files (`index.html`, `style.css`, `script.js`, `cv.pdf`) to the repository root and commit.
5. In the repository, open **Settings → Pages**. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
6. Wait for the deployment to finish. Your website should be available at `https://showkatme2009.github.io`.

If `showkatme2009.github.io` already exists, upload these files into that repository instead of creating a duplicate.
